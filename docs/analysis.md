# Analysis internals

Stillset decodes every video frame in timestamp order, requests compact YUV buffers, and renders batches of eight into grayscale proxies with a bounded task group. Results are restored to timestamp order before motion detection. Motion is measured on a 6 × 6 grid without copying whole frames into temporary arrays. Persistent movement in a localized region is treated as animation so it does not hold the whole screen in motion. Stable pauses of at least 40 ms are retained; pauses shorter than the 120 ms confirmation threshold are still exported. The sharpest, calmest frame in each interval supplies the export timestamp; the PNG itself is re-extracted from the original video.

Screen classification runs separately from capture selection. The hybrid analysis requires macOS 27 and keeps all processing local. Vision OCR reads each byte-unique 800-pixel proxy once, using two continuously refilled workers. The initial pass uses visible titles for naming and preserves unresolved states separately. Background refinement uses Foundation Models only for ambiguous grouping and names, including form state. Reliable visible titles still bypass the model; repeated inset form labels, uncertain headings and unknown surfaces use image analysis. A centered bright heading over a dimmed page identifies common bottom sheets, so the foremost picker overrides the background page. Forms receive empty, partially filled, filled or error state suffixes. Recognized titles are reused on model failure without repeating OCR. One bounded retry handles transient model errors; refusals go directly to fallback.

A small grayscale comparison nominates up to three nearby representatives (mean distance at most 8/255). Reliable text substitutions, added badges and substantially different visible content can reject matches locally. Matching text requires visual evidence before grouping: a conservative RGB tile comparison checks the foreground, while small numeric-list scrolls match the option labels, then compare the visible central band of their controls on both sides of the text. This avoids glyph rasterization differences and sticky-header clipping while preserving selection changes. The header is checked separately and the scrollbar gutter is excluded. Ambiguous pairs remain separate in the initial pass and alone use a structured Foundation Models image comparison during background refinement. Uncertain or failed comparisons retain separate states. These heuristics are experimental and need validation on real recordings, particularly unfamiliar overlay and control layouts. All timeline occurrences and original-resolution exports remain intact.

States are grouped before naming, so repeat visits reuse one naming request. Model sessions are created only if unresolved names need them, then prewarmed during grouping. Naming keeps two requests active with fixed chronological OCR titles and cached names as context; completion order cannot change prompts. A new import cancels the previous refinement, and stale results cannot overwrite a newer recording. Named links from the initial pass remain valid for existing clipboard and drag references. Semantic comparisons remain serial: a two-worker trial was slower and less reliable on the local model. SHA-256 reuses byte-identical captures and caches the last catalog. Successful names and comparison decisions, including different-state results, survive partial retries. The local and AI catalog modes have separate cache identities. Comparison results are cached by the two image digests (up to 512 pairs); failures and cancellations are not cached. The app indicates names supplied by Vision. If both methods fail, it displays Capture à examiner, with the chronological index kept in filenames. FeaturePrint nomination was removed after it excluded small scrolls from semantic review on real exports.

PNG export uses AVFoundation’s native batched image sequence with zero timestamp tolerances. Four original frames at a time are encoded concurrently; callbacks and filenames remain chronological, including duplicate timestamps.

Completed PNGs use chronological indices and safe screen names, for example `007_simulation-de-revenus-choix-de-marque.png`. Repeated visits retain their own index. Display names never contain em dashes. Dragging, copying, and saving use these filenames. Named files are hard links (or copies if linking fails), so references to the original streamed files remain valid during the session. Existing destination files are never overwritten.

## Current limits

The synthetic corpus exercises two scroll stops, navigation, return to an already-seen screen, full-resolution export, and copying exported PNGs; it is not a set of recordings from every listed iOS interaction. Generated-image tests cover exact duplicate grouping and safe indexed filenames. Synthetic OCR evidence tests cover small scrolls, changed selection controls on either side of the labels and fixed-header differences; they do not exercise Vision recognition end to end. Feature tests cover selection and dragging in the unique-screen view. Names remain proposals, not measured recognition accuracy. Semantic names alone never determine which captures are hidden. Direct image understanding can produce incorrect names or grouping. OCR bounding-box jitter can leave an equivalent scroll ambiguous; it remains separate. Contextual naming is optional and does not change which timestamps are retained. Localized animation masking is intentionally limited to regions covering at most 30% of the frame, so a large continuously moving video preview can still interrupt stability detection. Results are processed in one session and are not persisted between launches.
